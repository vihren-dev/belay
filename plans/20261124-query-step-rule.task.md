# The exact step of a query

Created 2026-11-24. Status OPEN. Audience is implementers and reviewers.

Slice 5 of [ADR 0033](../docs/adr/adr-0033-exact-step-rules.md) gives
queries an exact equation. From resolution alone a client can read each
clock, counter, support and output check. All modeled outcomes keep the
connection. A check of a sent query reaches each possible result in the
rest of the program. SELECT also retains its syntax-only entry point under
the conditions of D10. The ADR 0027 query and single contracts still hold.

A client fixture must prove an all-input or refusal claim on a variable
database. For each replaced law, the original premises must still entail
the original conclusion. Fixtures for a choice must check the continuation
on each result. QueryOutputFacts, ReadOnlyFrame, SqlRunKindRules and
SelectOutcomeCases contain the existing contracts and callers. Acceptance
includes the unchanged verdict, full checks, counts, timing and capability
records of D11.
