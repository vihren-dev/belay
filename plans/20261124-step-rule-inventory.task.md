# Complete the exact step rules

Created 2026-11-24. Status OPEN.

Every resolved statement has one applicable exact equation. Client proofs
can use each output, next connection and further execution in that
equation. The package exports no redundant partial law for a single kind.
Every retained group law has callers that need multiple kinds. The status
file records the classification of the step theorems and the reason for
each retained single-kind theorem under ADR 0033 D12.

A send uses an exact equation through the common send rule. A visible
SELECT can use the syntax rule under its original premises. The tactic
diagnoses a missing resolution and tells the reader how to prove such a
goal. The kernel checks the original contracts of the deleted laws on the
last revision of their dependencies. The status file identifies the Nix
acceptance of those witnesses before their removal and the reason for
each witness that remains.

The full suite checks the client proofs, diagnostics and axiom reports.
Conformance verdicts must match the previous slice. The simplification
milestone and D11 record use the same selected Lean files as the pilot.
