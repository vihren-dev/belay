## Progress

- 2026-10-15: task and status files, stacked on slice 5c (#136, #137). Native facts
  checked on SQLite 3.51.0: `OR FAIL` keeps the earlier rows and counts them; `OR IGNORE`
  skips key and NOT NULL failures and counts only inserted rows, but a rowid alias
  mismatch is still an error; `OR REPLACE` deletes every conflicting row, counts one
  change, and gives a NULL in a NOT NULL column its default; `OR ROLLBACK` in a
  transaction ends it (a later COMMIT fails); a constraint `ON CONFLICT REPLACE` is
  checked after the ABORT keys, so a row that conflicts on both fails without deleting;
  an `OR` clause overrides a constraint algorithm; an UPSERT target is handled before a
  constraint algorithm.

- 2026-10-16: native facts for the design: a rowid alias mismatch is ABORT under FAIL;
  `DO UPDATE` is checked with ABORT under every `OR` clause and constraint algorithm; a row
  that conflicts on an IGNORE key and a FAIL key fails with FAIL, an order that the model
  does not decide (restriction `mixed-conflict-algorithms`, next commit).
- 2026-10-16: the `OR` clause (first commit). Frontend: `insert_algorithm` in
  `belay/sqlite/syntax_conflicts.py` maps `INSERT OR algorithm` and `REPLACE INTO`; the
  syntax INSERT has an `algorithm` field. `ConflictAlgorithm` (`Resolution/ConflictAlgorithm.lean`)
  and `Resolved.ConflictPolicy` (one algorithm per key and per NOT NULL column); an INSERT
  whose algorithms are not all ABORT is `Resolved.Statement.upsert`. Execution:
  `UpsertRun.lean` (`failedConstraint`, `blockingKey`, `replaced`, `insertChecked`); errors
  `constraintFail` and `constraintRollback`; `SqlState.failed` rolls back a transaction.
  Proofs: `UpsertPreservation.lean`, `UpsertConforms.lean` (the final table and the table
  before a failing row are valid). Laws: `literal_cases` has a FAIL case,
  `statement_atomicity` excludes FAIL and ROLLBACK failures, and `constraint_rollback` is
  new. Evidence: `AlgorithmExamples.lean`, 20 authored cases
  (`conformance/authored_algorithms.py`, all AGREE), 6 mutants, the corpus 20 writer.
