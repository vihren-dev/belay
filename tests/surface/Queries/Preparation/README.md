# Queries / Preparation

Put code here when its subject is the resolution of names against the catalog, for all statements:
scopes, name traces, views, pragma sources, and the precedence of preparation errors.

This tree is the surface tests. Each file here is a Lean test file about that subject, which a
Python test of `tests/` compiles.

[The division](../README.md) lists the other teams of Queries.
