# Queries / Evaluation

Put code here when its subject is the evaluation of the parts of a query: sources, compound queries,
windows, expressions, groups, order, aggregates, three-valued logic and collations.

This tree is the surface tests. Each file here is a Lean test file about that subject, which a
Python test of `tests/` compiles.

[The division](../README.md) lists the other teams of Queries.
