# Frontend / Grammar

Put code here when its subject is the code that parses SQL with the grammar of one SQLite release
and translates the parse tree to the syntax of the model.

This tree is the SQL text package, which reads SQL text with the SQLite parser library.

A declaration with a different subject goes to the team of that subject, also when its only user is
in this directory. [The division](../README.md) lists the other teams of Frontend.
