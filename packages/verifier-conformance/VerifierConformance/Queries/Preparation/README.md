# Queries / Preparation

Put code here when its subject is the resolution of names against the catalog, for all statements:
scopes, name traces, views, pragma sources, and the precedence of preparation errors.

This tree is the conformance harness, which compares the model with native SQLite. This directory
holds the part of the harness that depends on the subject.

A declaration with a different subject goes to the team of that subject, also when its only user is
in this directory. [The division](../README.md) lists the other teams of Queries.
