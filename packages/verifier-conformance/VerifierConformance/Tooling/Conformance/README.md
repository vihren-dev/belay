# Tooling / Conformance

Put code here when its subject is the comparison of the model with native SQLite: code that runs a
case on native SQLite, compares the result with the prediction of the model, and the command-line
programs for this.

This tree is the conformance harness, which compares the model with native SQLite. This directory
holds the part of the harness that depends on the subject.

A declaration with a different subject goes to the team of that subject, also when its only user is
in this directory. [The division](../README.md) lists the other teams of Tooling.
