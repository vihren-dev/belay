# Queries / Evaluation

Put code here when its subject is the evaluation of the parts of a query: sources, compound queries,
windows, expressions, groups, order, aggregates, three-valued logic and collations.

This tree is the model library. This directory holds the definitions of the subject, the laws about
them, and their examples.

A declaration with a different subject goes to the team of that subject, also when its only user is
in this directory. [The division](../README.md) lists the other teams of Queries.
