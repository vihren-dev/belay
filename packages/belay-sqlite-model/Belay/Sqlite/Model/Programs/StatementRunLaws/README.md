# Programs / StatementRunLaws

Put code here when its subject is facts that connect the run of one statement to the semantics of
queries, writes and schema changes.

This tree is the model library. This directory holds the definitions of the subject, the laws about
them, and their examples.

A declaration with a different subject goes to the team of that subject, also when its only user is
in this directory. [The division](../README.md) lists the other teams of Programs.
