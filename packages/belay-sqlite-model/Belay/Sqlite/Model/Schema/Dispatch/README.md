# Schema / Dispatch

Put code here when its subject is the code that resolves and runs one statement of any kind: the
resolver, the step, the connection, and their fixtures.

This tree is the model library. This directory holds the definitions of the subject, the laws about
them, and their examples.

A declaration with a different subject goes to the team of that subject, also when its only user is
in this directory. [The division](../README.md) lists the other teams of Schema.
