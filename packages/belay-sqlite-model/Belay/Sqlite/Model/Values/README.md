# Values: values and functions

The division for the operations on SQL values and the built-in functions.

The teams of this division in this tree:

- [DateTime](DateTime/README.md): dates and times: the parser of time values, the modifiers, and the
  conversion to and from Julian days.
- [Json](Json/README.md): JSON: JSON text, JSONB bytes, the JSON functions and the JSON table
  functions.
- [Scalar](Scalar/README.md): scalar values and functions: text, numbers, conversion by affinity,
  `printf`, LIKE and GLOB.

A file of this division can import files of this division and of the divisions below it: Shared. It
cannot import a file of a division above it.
