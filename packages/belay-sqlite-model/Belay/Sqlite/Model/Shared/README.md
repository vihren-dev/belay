# Shared: shared model

The division for the types that more than one division uses.

The teams of this division in this tree:

- [Catalog](Catalog/README.md): the objects of a catalog, the catalog, and the value of a database.
- [Execution](Execution/README.md): the connection, the counters, and the effect, the outcome and
  the output of a run.
- [Resolved](Resolved/README.md): resolved statements and expressions, and the context, the state
  and the errors of preparation.
- [Syntax](Syntax/README.md): the syntax tree of statements and expressions.
- [Values](Values/README.md): the type of a value, identifiers, and the stored form of a value.

This is the lowest division. A file of this division imports only files of this division.
